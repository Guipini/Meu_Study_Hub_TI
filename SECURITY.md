# Política de segurança

Este repositório é um portfólio acadêmico público e não contém código em produção, credenciais nem dados de terceiros.

## O que está configurado

- **Repositório público**, para que a correção e o LinkedIn consigam acessá-lo.
- **Branch `main` protegida** por ruleset: não aceita force-push nem exclusão.
- **Secret scanning e push protection** ativados: o GitHub bloqueia o envio de chaves e tokens.
- **Autenticação em dois fatores** ativada na conta do autor.
- **CODEOWNERS** define o autor como responsável por todos os arquivos.

## Regras de conteúdo

- Não publicar senhas, tokens, chaves de API nem arquivos `.env`.
- Não publicar provas, listas com gabarito ou material de terceiros sem autorização.
- Dados pessoais ficam restritos ao que já é público no perfil do LinkedIn (nome e e-mail de contato).

## Como reportar um problema

Use a aba **Security > Report a vulnerability** do repositório (relato privado) ou escreva para gustavogs2002@gmail.com.
