# Meu_Study_Hub_TI

Portfólio acadêmico e profissional de **Gustavo Salerno**, aluno de Ciência da Computação no UniCEUB
(2026/2) e Cientista de Dados Pleno na Smurfit Westrock.

O Study Hub é o espaço onde organizo, disciplina por disciplina, como cada conteúdo da graduação se
conecta ao que já pratico profissionalmente (Python, SQL, R e machine learning), e onde registro essa
trajetória para acompanhamento próprio e, futuramente, como portfólio.
